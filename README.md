# Developer & Engineering Portfolio - Paras

A highly responsive, pixel-perfect, interactive engineering portfolio designed specifically for showcasing system architecture, full-stack achievements, technology stacks, education, and GitHub integrations.

## 🚀 Key Features

*   **Clean Cosmic Slate Aesthetics**: High-end typography, consistent contrast ratios (strict light/dark mode compliant), balanced negative space, and smooth layout animations powered by **motion**.
*   **Direct Mail Routing**: Simple, intuitive template-driven direct emailing directly through secure native mailbox clients via optimized `mailto` protocol mappings.
*   **Real-time GitHub Feed**: Fetches public activity/repositories (or simulates fallback telemetry gracefully) utilizing modern aesthetic cards.
*   **Dynamic Timeline Experience**: Clean, categorized job panels showcasing system architecture experience, core impact metrics, and technology badges.

## 🛠️ Technology Stack

*   **Core**: React 18, Vite, TypeScript
*   **Animations**: Motion (`motion/react`)
*   **Styling**: Tailwind CSS
*   **Icons**: Lucide React

## 📦 Getting Started

To run this project locally, execute the following commands in the workspace root:

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
